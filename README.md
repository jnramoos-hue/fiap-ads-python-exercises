# 🇧🇷 Português

## Sobre o repositório

Este repositório documenta parte da minha evolução acadêmica no curso de **Análise e Desenvolvimento de Sistemas da FIAP**, reunindo exercícios de lógica de programação e Python desenvolvidos ao longo das primeiras fases da graduação.

Mais do que armazenar arquivos, este espaço funciona como uma **linha do tempo prática de aprendizagem**. Cada exercício registra um novo contato com conceitos, formas de resolver problemas, testes, correções e melhorias realizadas durante o estudo.

> **A proposta não é apresentar códigos perfeitos desde o início, mas tornar visível a evolução do raciocínio e da prática.**

---

## A jornada registrada

```text
Compreensão do problema
          ↓
Construção do algoritmo
          ↓
Representação em pseudocódigo
          ↓
Primeiras implementações em Python
          ↓
Condições, repetições e coleções
          ↓
Funções e organização da lógica
          ↓
Arquivos e persistência básica
          ↓
JSON, XML e dados estruturados
          ↓
Evolução contínua
```

O repositório acompanha a passagem de soluções simples e sequenciais para programas capazes de tomar decisões, repetir tarefas, organizar dados e interagir com arquivos externos.

# 🇬🇧 English

## About this repository

This repository documents part of my academic development in FIAP's **Systems Analysis and Development** program. It contains programming-logic and Python exercises developed throughout the first stages of the degree.

More than a collection of files, this repository works as a **practical learning timeline**. Each exercise represents contact with a new concept, a problem-solving approach, testing, correction, or improvement made during the learning process.

> **The goal is not to present perfect code from the beginning, but to make the development of reasoning and practice visible.**

---

## Learning path

```text
Understand the problem
          ↓
Design the algorithm
          ↓
Represent it with pseudocode
          ↓
Build the first Python programs
          ↓
Use conditions, loops, and collections
          ↓
Organize logic with functions
          ↓
Work with files and basic persistence
          ↓
Use JSON, XML, and structured data
          ↓
Continuously improve
```
