# 🇧🇷 Português

## Sobre esta fase

Esta pasta registra os primeiros passos da jornada com **algoritmos, pseudocódigo e Python**. O foco principal é aprender a interpretar um problema, organizar uma solução em etapas e somente depois transformar esse raciocínio em código.

Os arquivos visíveis nesta fase incluem exercícios de pseudocódigo, calculadoras, operações numéricas, arredondamento, cálculo de tempo, comentários, manipulação de nomes e média de alunos.

> **Antes de programar soluções maiores, esta fase desenvolve a habilidade fundamental de decompor problemas em instruções claras.**

---

## Jornada de aprendizagem

```text
Problema
   ↓
Entradas necessárias
   ↓
Processamento
   ↓
Saída esperada
   ↓
Pseudocódigo
   ↓
Implementação em Python
   ↓
Teste e correção
```

---

<div align="center">

| 🧠 Lógica | 📝 Pseudocódigo | 🐍 Python |
|:---:|:---:|:---:|
| Decomposição de problemas | Representação da solução | Primeiras implementações |
| Sequência de passos | Entrada, processamento e saída | Variáveis e operações |
| Interpretação de requisitos | Preparação antes do código | Interação pelo terminal |

- construção de algoritmos sequenciais;
- declaração e utilização de variáveis;
- entrada e saída de dados;
- operações aritméticas;
- conversões e arredondamentos;
- organização inicial do código;
- utilização de comentários;

---

## O que os exercícios representam

Os exercícios mostram a passagem do raciocínio escrito para a execução prática. Calculadoras e problemas numéricos ajudam a consolidar o fluxo:

```text
Receber dados → Processar valores → Apresentar resultados
```

A simplicidade dos primeiros programas é intencional: cada atividade constrói uma parte da base necessária para condições, repetições, funções e estruturas de dados.

# 🇬🇧 English

## About this phase

This folder documents the first steps in **algorithms, pseudocode, and Python**. The main goal is to interpret a problem, organize a solution into clear steps, and only then transform that reasoning into code.

The visible files include pseudocode exercises, calculators, numerical operations, rounding, time calculations, comments, name manipulation, and student-average exercises.

> **Before building larger programs, this phase develops the essential ability to decompose problems into clear instructions.**

---

## Learning outcomes

- design sequential algorithms;
- identify inputs, processing, and outputs;
- represent solutions through pseudocode;
- declare and use variables;
- perform arithmetic operations;
- read user input and display results;
- test programs with different values;
- document the first stage of Python development.
