# 🇧🇷 Português

## Sobre esta fase

Esta pasta registra a ampliação da lógica de programação em Python. Depois dos programas sequenciais, as atividades passam a trabalhar decisões, repetições, operadores, coleções e funções.

A organização visível no repositório inclui áreas de exercícios, atividades acadêmicas, condicionais, fundamentos de operadores, laços, funções, listas e tuplas.

> **Nesta fase, o programa deixa de apenas seguir uma sequência fixa e passa a escolher caminhos, repetir tarefas e organizar conjuntos de dados.**

---

## Jornada de aprendizagem

```text
Variáveis e operadores
          ↓
Expressões booleanas
          ↓
Estruturas condicionais
          ↓
Laços de repetição
          ↓
Listas e tuplas
          ↓
Funções
          ↓
Problemas mais completos
          ↓
Código mais organizado
```

## Competências desenvolvidas

- operadores aritméticos, relacionais e lógicos;
- decisões com estruturas condicionais;
- repetições controladas por condições ou intervalos;
- variáveis de controle, contadores e acumuladores;
- listas e operações sobre sequências;
- tuplas e estruturas imutáveis;
- definição e chamada de funções;
- parâmetros e valores de retorno;
- decomposição de problemas maiores;
- organização progressiva dos exercícios por assunto.

---

## Evolução do raciocínio

```text
Código sequencial
      ↓
Código que reage a condições
      ↓
Código que automatiza repetições
      ↓
Código que organiza vários valores
      ↓
Código dividido em funções reutilizáveis
```

Essa progressão prepara a base para trabalhar com arquivos, formatos de dados e integrações em fases posteriores.

# 🇬🇧 English

## About this phase

This folder documents the expansion of programming logic with Python. After sequential programs, the exercises move toward decisions, loops, operators, collections, and functions.

The visible repository structure includes exercises, academic activities, conditionals, operator fundamentals, loop fundamentals, functions, lists, and tuples.

> **In this phase, programs stop following only a fixed sequence and begin selecting paths, repeating tasks, and organizing groups of data.**

---

## Learning outcomes

- use arithmetic, relational, and logical operators;
- build conditional flows;
- automate tasks with loops;
- work with counters and accumulators;
- organize values using lists and tuples;
- define reusable functions;
- use parameters and return values;
- decompose larger problems;
- structure exercises by programming topic.
