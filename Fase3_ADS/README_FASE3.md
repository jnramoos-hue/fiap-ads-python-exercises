# 🇧🇷 Português

## Sobre esta fase

Esta pasta registra a evolução dos exercícios para além dos dados mantidos apenas durante a execução do programa. O foco passa a incluir leitura, escrita, configuração e representação estruturada de informações.

Os arquivos visíveis incluem exemplos com arquivos de texto, uso de `open`, bloco `with`, leitura e escrita de conteúdo, dicionários convertidos para JSON, XML, arquivo de configuração INI e uma agenda estruturada em JSON.

> **Nesta fase, os dados deixam de existir apenas na memória e passam a ser armazenados, recuperados e compartilhados em formatos externos.**

---

## Jornada de aprendizagem

```text
Dados em memória
      ↓
Abertura de arquivos
      ↓
Leitura de conteúdo
      ↓
Escrita e atualização
      ↓
Gerenciamento seguro com with
      ↓
Dicionários e serialização
      ↓
JSON e XML
      ↓
Arquivos de configuração
      ↓
Persistência básica
```

## Competências desenvolvidas

- abertura e fechamento de arquivos;
- leitura de conteúdo textual;
- escrita e atualização de arquivos;
- uso seguro de recursos com o bloco `with`;
- transformação entre dicionários Python e JSON;
- leitura e organização de estruturas JSON;
- contato com XML como formato estruturado;
- utilização de arquivos INI;
- configuração com `ConfigParser`;
- compreensão inicial de persistência e intercâmbio de dados.

---

## Evolução do raciocínio

```text
Programa processa valores
          ↓
Programa salva informações
          ↓
Programa recupera informações
          ↓
Programa interpreta formatos estruturados
          ↓
Programa separa dados, código e configuração
```

Essa progressão aproxima os exercícios de situações reais encontradas em aplicações, automações, APIs e sistemas que precisam manter informações entre diferentes execuções.

# 🇬🇧 English

## About this phase

This folder documents the transition beyond data that exists only while a program is running. The exercises introduce reading, writing, configuration, and structured representations of information.

The visible files include text-file examples, `open`, the `with` statement, content reading and writing, Python dictionaries converted to JSON, XML examples, INI configuration, and a JSON-based contact list.

> **In this phase, data moves beyond memory and begins to be stored, retrieved, and shared through external formats.**

---

## Learning outcomes

- open and close files;
- read textual content;
- write and update files;
- safely manage resources with `with`;
- convert between Python dictionaries and JSON;
- interpret structured JSON data;
- understand XML as a structured format;
- work with INI configuration files;
- use `ConfigParser`;
- establish a foundation for persistence and data exchange.
